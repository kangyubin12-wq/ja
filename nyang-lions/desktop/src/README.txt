꾹꾹이즈 - 바탕화면 고양이 (윈도우 10/11)

[설치]
1. 이 압축 파일을 풀어요. (압축 풀기 -> 모두 압축 풀기)
2. 폴더 안의 install.bat 을 더블클릭해요.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] -> [실행]
   - 처음 한 번만 실행 엔진(약 110MB)을 내려받아요. 1~3분 걸려요.
   - 예전 "냥이 라이온즈"가 깔려 있으면 자동으로 꾹꾹이즈로 바뀌고, 키우던 기록도 그대로예요.
3. 끝나면 고양이가 화면 오른쪽 아래에 나타나고, 바탕화면에 [꾹꾹이즈] 아이콘이 생겨요.

[사용법]
- 달걀 몸체를 끌면 원하는 곳으로 옮겨져요. 두 번 클릭하면 크게 열려요.
- 화면 아래 아이콘 : 밥, 놀기, 쓰담, 씻기, 재우기, 훈련
- 훈련 중에는 버튼이나 화면을 눌러 스윙
- 고양이 위에서 우클릭 : 행동, 크게 열기, 크기, 항상 위에 두기, PC 켤 때 자동 실행, 업데이트 확인, 숨기기, 종료
- 작업표시줄 오른쪽 아래(트레이)의 고양이 아이콘 : 보이기 / 숨기기 / 업데이트 확인 / 종료

[업데이트]
- 이 버전부터는 켜져 있을 때 새 버전을 저절로 받아서 다시 켜져요. (켤 때 + 6시간마다 확인)
- 바로 확인하고 싶으면 우클릭 -> [업데이트 확인]
[삭제] uninstall.bat 을 실행해요.
